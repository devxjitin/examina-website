SETUP GUIDE

Five steps to get started.

Before you begin

Have a Windows 10/11 PC, an internet connection, the Examina delivery ZIP and your purchased licence key ready. You also need your own Gemini API key.

Need a licence? Contact us →

  1. Extract the delivery files

    Right-click the Examina ZIP and choose Extract All. Extract into a folder such as C:\Examina. Keep Examina.exe and Examina.txt together. Run the app from the extracted folder, not from inside the ZIP.

  2. Get your Gemini API key

    Open Google AI Studio's API key page ↗, sign in and create an API key. Copy it for the next step. Keep it private. Usage availability, quotas and any charges depend on your Google account.

  3. Add your two keys

    Open Examina.txt in Notepad. Paste your Gemini API key after EXAMINA_API_KEY= and your purchased licence key after EXAMINA_LICENCE=. Leave the other settings unchanged, save with Ctrl + S, then close Notepad.

    EXAMINA_API_KEY=your-gemini-api-key
EXAMINA_LICENCE=your-purchased-licence-key

    These are placeholders. Use your own keys. If you received only the app, running it once creates the settings file; quit the running copy before restarting after setup.

  4. Start Examina

    Double-click Examina.exe. No app window opens; use the keyboard shortcuts below. At startup, the cursor moves to the centre when the licence is valid, or shakes if the licence check fails. If Windows blocks the app or you are unsure about its source, contact us before continuing.

  5. Open your exam question

    Keep the complete question and answer area visible on your primary display. Close unrelated sensitive content, choose the appropriate shortcut and review the result carefully.

USAGE INSTRUCTIONS

Your everyday practice routine.

Start Examina each time you want to practise. Hold Ctrl + Alt + Shift, press the mode's letter, then release the keys. Wait for the response to finish before starting another question.

Keyboard shortcuts
ShortcutUse it for
Ctrl + Alt + Shift + QSingle-answer multiple-choice practice; selects an option.
Ctrl + Alt + Shift + MMultiple-select practice; updates the selected choices.
Ctrl + Alt + Shift + STheory and written explanations; types an answer.
Ctrl + Alt + Shift + CCoding exercises; types a suggested solution.
Ctrl + Alt + Shift + ZStop an answer while it is being typed.
Ctrl + Alt + Shift + XQuit Examina.

Review selected answers, read explanations and test suggested code. AI can make mistakes. Only use AI assistance where it is explicitly permitted.

Changing your settings

Edit and save the settings file beside the copy of Examina you run. After changing your licence key, quit and restart the app. If a newly added API key is not picked up, restart Examina too.

Moving to another computer

Quit Examina, then securely copy the whole folder, including both files, to the other Windows PC. Keep the settings file private. The new computer needs internet access, and your licence's device allowance still applies. Contact us if activation fails or you need help moving your licence.

Get personal setup help →
Nothing happens when I use a shortcut.

Start Examina and allow time for the licence check. Hold all three modifier keys, then press the mode letter. Keep the complete question on your primary screen. A second request is ignored while one is running.

The cursor shakes at startup.

Check your internet connection and the licence key in Examina.txt. Save the file, quit and restart Examina. If it continues, contact us about validity or device allowance. Do not send your keys in the contact form.

The answer appears in the wrong place.

Stop typing with Ctrl + Alt + Shift + Z. Make sure the question and answer field are fully visible on your primary display before trying again. Review all answers before using them.

My settings changes are ignored.

Save Examina.txt and make sure it is beside the Examina.exe you actually started. Quit and restart after a licence change or if a newly added key is not picked up.

I see an API limit or connection problem.

Check your internet connection and your API account's usage limits. Wait before retrying. If the issue continues, contact us with a description of what happened, without sharing API keys, licence keys or sensitive screen content.
