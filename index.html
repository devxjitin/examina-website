Five steps to get started.

Before you begin

Have a Windows 10/11 PC, an internet connection, the Examina delivery ZIP and your purchased licence key ready. You also need your own Gemini API key.

Need a licence? Contact us →

  1. Extract the delivery files

    Right-click the Examina ZIP and choose Extract All. Extract into a folder such as C:\Examina. Keep Examina.exe and Examina.txt together. Run the app from the extracted folder, not from inside the ZIP.

  2. Get your Gemini API key

    Open Google AI Studio's API key page ↗, sign in and create an API key. Copy it for the next step. Keep it private. Usage availability, quotas and any charges depend on your Google account.

  3. Add your two keys

    Open Examina.txt in Notepad. Paste your Gemini API key after EXAMINA_API_KEY= and your purchased licence key after EXAMINA_LICENCE=. Leave the other settings unchanged, save with Ctrl + S, then close Notepad.

    EXAMINA_API_KEY=your-gemini-api-key
EXAMINA_LICENCE=your-purchased-licence-key

    These are placeholders. Use your own keys. If you received only the app, running it once creates the settings file; quit the running copy before restarting after setup.

  4. Start Examina

    Double-click Examina.exe. No app window opens; use the keyboard shortcuts below. At startup, the cursor moves to the centre when the licence is valid, or shakes if the licence check fails. If Windows blocks the app or you are unsure about its source, contact us before continuing.

  5. Open your exam question

    Keep the complete question and answer area visible on your primary display. Close unrelated sensitive content, choose the appropriate shortcut and review the result carefully.

What to know about getting started
and answering exam questions.

What is Examina?

Examina is a Windows AI answer assistant. Use a keyboard shortcut to select multiple-choice options or type a suggested written or coding answer into the answer area. Review the result before continuing.

What do I need to get started?

A Windows 10 or 11 PC, an internet connection, an Examina licence and your own Gemini API key. Google’s free tier is enough to start, so there is usually no extra AI cost. Add your keys to Examina.txt next to the app, then restart Examina. Keep this settings file private.

Does Examina help with exam questions?

Yes. Examina provides AI assistance for multiple-choice, multiple-select, coding and written exam questions. Choose the matching keyboard shortcut to select options or type a response, then review the result.

Will every answer be correct?

No. AI responses can be incomplete or incorrect. Review answers, test suggested code and check important details against your learning materials.

Does Examina have a dashboard?

No. Examina runs in the background and you control it through keyboard shortcuts. The slideshow shows illustrative examples of quiz, written and coding assistance; it is not an app screenshot.

What should I know about privacy?

Visible screen content is shared with an external AI service to provide assistance. Close unrelated sensitive content before using the app, and keep your API and licence keys private.

How do I get pricing and licence details?

Lite is ₹199 for 1 day and Go is ₹999 for 1 week, with 50% off both plans. See the plans → Message us on WhatsApp to buy your licence directly from us or ask a question.

What is the difference between Lite and Go?

Both include all four answer modes. Lite costs ₹199 for 1 day; Go costs ₹999 for 1 week, about ₹143 per day.

Nothing happens when I use a shortcut.

Start Examina and allow time for the licence check. Hold all three modifier keys, then press the mode letter. Keep the complete question on your primary screen. A second request is ignored while one is running.

The cursor shakes at startup.

Check your internet connection and the licence key in Examina.txt. Save the file, quit and restart Examina. If it continues, message us on WhatsApp. Do not share your API or licence keys in messages.

I see an API limit or connection problem.

Check your internet connection and your API account’s usage limits. Wait before retrying. If the issue continues, contact us without sharing keys or sensitive screen content.
