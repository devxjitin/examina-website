A FEW GOOD QUESTIONS

Before your
first session.

What to know about getting started
and answering exam questions.

What is Examina?

Examina is a Windows AI answer assistant. Use a keyboard shortcut to select multiple-choice options or type a suggested written or coding answer into the answer area. Review the result before continuing.

What do I need to get started?

A Windows 10 or 11 PC, an internet connection, an Examina licence and your own Gemini API key. Add your keys to Examina.txt next to the app, then restart Examina. Keep this settings file private.

Does Examina help with exam questions?

Yes. Examina provides AI assistance for multiple-choice, multiple-select, coding and written exam questions. Choose the matching keyboard shortcut to select options or type a response, then review the result.

Will every answer be correct?

No. AI responses can be incomplete or incorrect. Review answers, test suggested code and check important details against your learning materials.

Does Examina have a dashboard?

No. Examina runs in the background and you control it through keyboard shortcuts. The slideshow shows illustrative examples of quiz, written and coding assistance; it is not an app screenshot.

What should I know about privacy?

Visible screen content is shared with an external AI service to provide assistance. Close unrelated sensitive content before using the app, and keep your API and licence keys private.
